Telegram: if the server can't read the first step of the secure connection ("The server forgot this session"), the next try uses the older way Telegram also accepts.
Telegram checks the real time on the internet before connecting, so a clock set to local time doesn't stop it.
While connecting, Telegram shows the step it is on. Type "telegram log" in the Terminal to see the last steps.
After an update, this window shows what changed.
