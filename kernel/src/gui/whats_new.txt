RyzikOS is faster: the launcher, search, menus, window shadows and text are drawn about twice as fast, so opening, moving and animating windows is smoother. Nothing looks different, and every animation is still there.
Starting from the CD takes a couple of seconds less: GRUB no longer unpacks the whole system twice, and the system itself is smaller.
On the live CD, opening the launcher no longer copies the whole system in memory on every frame, which made it stutter.
